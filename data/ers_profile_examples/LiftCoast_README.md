# Lift-and-coast timing (v0.10.14)

Подсказка для игрока, без управления газом, тормозом или режимом ERS.
Работает при запущенной записи, включая ERS Off/Dry-run, в одиночной и сетевой игре.
Использует только телеметрию игрока. Карточка обновляется каждые 50 мс.

## Настройка

1. Открыть `Open ERS profiles` и выбрать уже используемый JSON трассы.
2. Добавить верхнеуровневое поле `lift_coast` из примера ниже.
3. Заменить примерные координаты проверенными точками своей трассы/конфигурации.
4. Установить `enabled: true`, сохранить JSON и перезапустить запись.
5. Нажать `Open overlay`. В `Edit overlay` карточку **LIFT & COAST** можно перемещать,
   масштабировать и скрывать. Кнопка `Show all` возвращает скрытую карточку.

Числа ниже показывают формат и **не являются рекомендацией для какой-либо трассы**.
Встроенные профили не получают непроверенные точки автоматически.

```json
"lift_coast": {
  "enabled": false,
  "preview_distance_m": 300,
  "minimum_speed_kph": 100,
  "suppress_on_pit_lap": true,
  "zones": [
    {
      "id": "t1-coast",
      "corner": "T1",
      "corner_distance_m": 1000,
      "lift_before_corner_m": 250,
      "brake_before_corner_m": 100
    }
  ]
}
```

- `corner_distance_m`: координата согласованного ориентира поворота в UDP `lapDistance`,
  измеренная от линии старта. Для показаний «за N м до поворота» следует привязать
  ориентир к трассовым табличкам. Геометрический апекс не обязательно совпадает
  с нулём дистанции табличек. Нужна проверка в игре.
- `lift_before_corner_m`: расстояние от этого ориентира, где появляется «ОТПУСТИ ГАЗ».
- `brake_before_corner_m`: граница, после которой сигнал сброса заканчивается.
  Это не команда начать торможение и не новая точка торможения.
- `preview_distance_m`: за сколько метров до точки сброса показывать отсчёт.
- `suppress_on_pit_lap`: приостанавливать советы, когда активна переменная
  pit-lap burn существующего автопилота. При ERS Off эта переменная не считывается.

Для примера при `lapDistance = 600` карточка покажет:
«T1 · сброс через 150 м / Сброс за 250 м до поворота».
При 750 м покажет «ОТПУСТИ ГАЗ», после отпускания «ГАЗ ОТПУЩЕН»;
при 900 м или нажатии тормоза «ЗОНА ТОРМОЖЕНИЯ».

## Выбор и ограничения

Используется тот же порядок выбора профиля, что у ERS: трасса, session_types,
сухие/мокрые условия, actual_tyre_compounds / visual_tyre_compounds, приоритет.
Если для Soft, Medium, Hard, Intermediate или Wet используются отдельные профили,
добавить проверенные точки в каждый соответствующий профиль. Профили без ограничений
по составу применяются ко всем совместимым шинам, как раньше.
Если выбран профиль без `lift_coast`, показано «Нет точек в профиле трассы»;
точки из другого профиля не заимствуются. Старые JSON остаются совместимыми.

Подсказки приостанавливаются в пит-лейне, на in/out lap, при паузе/сетевой паузе,
наблюдении, SC/VSC/formation, неактивном результате и несовпадении длины трассы
более чем на 10 м. Не используются отрицательные предстаровые координаты.
Lap/Telemetry должны быть не старше 250 мс, Status 1500 мс, Session 3000 мс.
Без новых пакетов сигнал исчезает. После FLBK очищаются данные игрока;
пакеты отменённой ветки по overall frame не могут восстановить сигнал.

Зоны поддерживают пересечение линии старта. Окна от предпросмотра до поворота
не должны пересекаться. Неверный блок отклоняет профиль с сообщением в журнале
загрузки ERS. Проверить выбранный профиль после редактирования.

Это фиксированные проверяемые точки: приложение не утверждает, что они оптимальны,
не оценивает выигрыш энергии/времени и не компенсирует реакцию водителя автоматически.
Для калибровки сравнивать сопоставимые проезды по времени до следующего выхода,
топливу, восстановленной и потраченной энергии. Больший SOC сам по себе не доказывает
выгоду. Подсказки по торможению и управление педалями не добавлены.
