# Racecraft analysis

Racecraft must be analysed separately from clean pace.

## 1. Find matched battle vs clear-air windows

Prefer natural A/B comparisons within:
- the same stint;
- same compound;
- similar tyre age;
- similar fuel regime;
- no major damage.

Compare:
- lap median;
- sector times;
- selected technical sections;
- gap ahead/behind;
- speed/inputs where useful.

The goal is to estimate the cost of proximity, not merely to observe that a battle lap was slower.

## 2. Dirty-air / execution cost

If a technical section worsens with a car ahead:
- quantify sector loss;
- identify which corners/blocks create it;
- distinguish aerodynamic/line restriction from overdriving;
- check steering corrections and minimum speed;
- check whether the driver is braking later merely to maintain visual proximity.

A useful recommendation may be to create a small additional gap before a technical sequence if the recovered corner time exceeds the lost tow/proximity.

State the measured range, for example:
"battle S1 costs approximately 0.5-0.8 s".

## 3. Attack and defence

Assess whether time loss comes from:
- compromised entry;
- defensive line;
- overtaking attempt;
- being boxed in;
- early ERS spend;
- poor positioning for the next sequence.

Do not interpret every slower battle lap as a driving mistake.

## 4. Flashbacks and battle load

Where possible associate FLBK with:
- gap ahead;
- gap behind;
- corner/track distance;
- battle state.

Use this only as evidence of execution load, not proof of causality.

Pit/debug FLBK must be removed first.

## 5. Position and result context

Explain when finishing position differs from underlying pace due to:
- pit cycles;
- alternate strategies;
- attrition;
- traffic;
- Safety Car;
- fuel saving.

The report must distinguish:
- race result;
- clean pace;
- racecraft execution.

## 6. Measurable racecraft prescription

Recommendations should be specific:
- create +0.15-0.30 s before Esses;
- preserve one steering input;
- avoid defending corner X if it ruins Y/Z;
- save ERS for the higher-value passing zone.

Do not use generic "be more patient" language without telemetry evidence.
