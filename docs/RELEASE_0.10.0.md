# F1 Telemetry Lab v0.10.0

## Что изменилось

Версия 0.10.0 объединяет три изменения: Live Race Engineer, обучаемые профили трасс и минимальный формат архива.

Во время гонки приложение показывает последние три завершённых круга, текущий износ шин с диапазоном оставшегося ресурса, ожидаемую позицию после пит-стопа и рекомендацию по агрессивности ERS. Те же данные доступны в отдельном always-on-top оверлее.

Все приближённые значения явно помечены диапазоном и confidence. Незавершённый круг не участвует в оценке темпа износа. Invalid, pit и SC/VSC laps также исключаются.

## Первый профиль

Встроенный `China_Race.json` содержит:

- safe tyre wear 75%;
- базовые wear priors по compound;
- green/VSC/SC pit loss и неопределённость;
- ERS target corridors по участкам T1 -> T4, T6 -> T10, T10 -> T13, T13 -> T14, T14 -> T16 и T16 -> T1.

После каждой успешно проанализированной сессии средний wear rate и pit loss обновляются в `<root>/race_profiles/learned/Track_2.json`. Каждая `session_uid` учитывается один раз.

## Новый формат сессии

Автоматически создаётся только `session.sqlite`. В нём находятся raw packets, производные таблицы, качество, ERS audit, выбранные профили и история анализа.

При включённом Auto RAR приложение вызывает WinRAR с RAR5 и максимальным сжатием. В архиве находится ровно один файл `session.sqlite`. Перед архивированием создаётся отдельный SQLite backup, выполняются `VACUUM` и `integrity_check`, после архивирования запускается `WinRAR t`.

WinRAR должен быть установлен или указан в Settings. ZIP fallback отсутствует. Если WinRAR недоступен, анализ и рабочая база остаются сохранены.

## Excel

Кнопка `Export race summary` создаёт небольшой `race_summary.xlsx` с пятью листами:

1. Laps
2. Tyres
3. Pits
4. ERS
5. Quality

Excel создаётся только вручную и не включается в RAR.

## Первый запуск

1. Установить WinRAR и при необходимости указать путь к `WinRAR.exe` в Settings.
2. Включить UDP format 2026 и 60 Hz.
3. Начать запись.
4. При желании открыть Race Engineer overlay.
5. После гонки нажать Stop и дождаться анализа и проверки RAR.

Для ERS Autopilot сохраняются прежние требования: ERS Assist Off, F7/F8, сначала Dry-run, только офлайн и F12 как emergency stop.
