# F1 Telemetry Lab 0.8.0

## Новое направление

0.8.0 перестраивает основной пользовательский сценарий вокруг последующего разбора сессии, а не вокруг попытки заменить полноценного аналитика набором экранных графиков.

Главный поток:

```text
F1 25 / Season 2026 -> recording -> session.sqlite -> analysis pack -> detailed race analysis
```

Существующие экраны анализа пока сохранены, чтобы смена направления не ломала рабочие функции без необходимости.

## Prepare analysis pack

На вкладке Sessions добавлена отдельная кнопка `Prepare analysis pack` / `Подготовить архив для анализа`.

Для выбранной сессии создаётся один ZIP, который можно отправлять на разбор без ручной подготовки файлов.

## Состав архива

- `session.sqlite` - полный согласованный снимок базы, включая raw UDP packets и производные таблицы;
- `chatgpt_pack.sqlite` - компактная проекция для быстрых запросов;
- `session_summary.json` - метаданные сессии, результат игрока, статистика кругов и перечень таблиц;
- `setup.json` - снимки и изменения настроек машины игрока;
- `events.json` - события, подтверждённые flashback и подозреваемые reset состояния;
- `data_quality.json` - диагностика качества записи и анализа;
- `track.json` - идентификатор, название и длина трассы, тип сессии и число кругов;
- остальные sidecar-файлы сессии, если они присутствуют.

## Почему полный session.sqlite снова включён

Compact pack полезен для быстрых запросов, но не может заменить исходную базу. Если ошибка парсера затронула производные таблицы, raw UDP packets позволяют восстановить данные повторным анализом. Именно так был обнаружен и исправлен случай с игроком на `car_idx 21`.

Поэтому в 0.8.0 ZIP хранит оба представления данных.

## Целостность SQLite

`session.sqlite` не копируется напрямую. Архиватор использует SQLite Backup API и создаёт отдельный согласованный snapshot. Это исключает зависимость архива от `-wal` / `-shm` файлов и позволяет получить корректную базу даже при незавершённом WAL checkpoint.

## 24-car support

Исправление 0.7.1 сохранено без изменений. Все фиксированные 24-slot массивы UDP 2026 читаются полностью, поэтому vehicle indices 20-23 не отбрасываются из-за `m_numActiveCars`.

## Совместимость

Database schema остаётся версии 5. Миграция существующих `session.sqlite` не требуется.
